# 0015. 상품 목록/상세 조회 공개

## 상태
확정

## 배경
SecurityConfig는 permitAll에 등록되지 않은 경로를 모두 인증 필요로 처리하므로,
Product API를 추가하면 로그인한 사용자만 상품을 조회할 수 있게 됨.
비로그인 사용자의 조회 허용 여부를 정할 필요가 생김.

## 고민한 선택지
1. 모든 상품 API를 인증 필요로 유지
2. 목록/상세 조회만 공개하고, 등록은 인증, 수정/삭제는 판매자 본인만 허용

## 결정
2번 채택. 공개 규칙은 GET 메서드에만 적용하고, 상세 경로는 숫자 ID로 제한함.

## 이유
- 가입 전에 상품을 탐색하는 흐름을 지원함.
- 최소 프론트(ADR 0003)의 첫 화면인 상품 목록을 비로그인 상태로 시연할 수 있음.
- 상세 경로를 숫자 ID로 제한해, 같은 접두사 아래 추가될 경로가 공개 규칙에
  의도치 않게 포함되지 않도록 함.

## 트레이드오프
- 인증 여부(SecurityConfig)와 변경 권한(판매자 본인 여부)을 판단하는 위치가
  나뉨. 판매자 본인 검증은 Service에서 수행하며, 등록 시 판매자는 요청 본문이
  아닌 인증된 회원 ID로 지정함.
- 조회 응답을 로그인 여부와 무관하게 동일하게 만들어, 개인화된 정보는 포함하지 않음.
- 공개 조회 경로에서 만료/위조 토큰은 ADR 0012의 필터 정책에 따라 인증 정보 없이
  통과하므로 익명 요청으로 허용됨.
