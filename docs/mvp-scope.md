# MVP 범위

## 1. 회원 (Auth)
- 회원가입 / 로그인 / 로그아웃 (JWT)
- 내 정보 조회/수정

## 2. 상품 (Product)
- 등록 / 목록조회(페이징) / 상세조회 / 수정 / 삭제
- 카테고리 필터링, 제목 검색
- 상품 상태: 판매중 → 예약중 → 판매완료

## 3. 거래 (Transaction) — 네고 포함
(관련 결정: [`0002-purchase-request-negotiation.md`](./decisions/0002-purchase-request-negotiation.md))

- 구매자가 희망 가격 제시하며 구매 요청 (정가 그대로 요청도 가능)
- 판매자가 요청에 대해 수락 / 거절 (재협상 없이 단순하게)
- 수락되면 → 상품 상태 `예약중`으로 변경, 거래 확정
- **실제 만남 시간/장소 조율은 서비스 범위 밖** (채팅 기능이 Tier 2로
  분류되어 있어, MVP에서는 거래 당사자 간 협의 수단을 제공하지 않음)
- 판매자가 수동으로 "거래 완료" 처리 → 상품 상태 `판매완료`
- 내 거래 내역 조회 (구매자/판매자 관점 각각)
- 한 상품에 여러 명이 동시에 구매 요청 가능 → 판매자가 그중 하나
  수락하면 나머지는 자동 거절 처리

## 4. 이번 MVP에서 제외 (Tier 2로 유지)
- 실시간 채팅
- 찜하기/좋아요
- 리뷰/평점
- 알림
- 이미지 다중 업로드 (1장만)
- 가격 재협상
